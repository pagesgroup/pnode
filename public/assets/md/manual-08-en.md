# Description of the control procedures
##
Start-up
- Check whether all safety features and guides are in correct order and present.
- Make sure there are no loose products in the machine.
- Check that all emergency stop buttons are released.

1. Close the doors.
1. Set the main switch to 'ON'.

## Operating modes
### Selection
Select the operating mode using the key switch on the primary control panel (See §6.1) to switch between 'Semi/Auto' and the automatic mode.
- 'Auto', Automatic mode, to run production.
- 'Semi', for semi-automatic selected, Semi automatic mode, to run automatic step by step.

Only if the machine runs in semi-automatic mode it is possible to select I/O test mode on the display.  
  
One of the three signals in the bottom right corner of the main screen lights up to indicate the mode the machine is running.

### Automatic mode
1. The machine is stopped.
1. Set selector switch in the position 'Auto'.
1. Press the start button on the 'Control Panel'.
1. When the start procedure is completed, the machine is ready to operate in automatic mode. The PackML state is 'execute' now and the machine will run production.

### Semi-Automatic mode
1. The machine is stopped.
1. Set selector switch in the position 'Semi'.
1. Slect Semi-automatic with the button on the main screen.
1. Press the start button on the 'Control Panel'.
1. When the start procedure is completed, the machine is ready to operate in semi-automatic mode. The machin runs sa step further when you push the pushbutton 'Semi-Auto control'.
1. Carry out the desired checks or changes.

### I/O test mode
1. The machine is stopped.
1. Set selector switch in the position ‘Semi’.
1. Select I/O test with the button on the main screen.
1. Press the start button on the ‘Control Panel’. 
1. When the start procedure is completed, the machine is ready to operate in IO/Test mode. In the Info screen of each equipment module you can operate in manual valves and motors. 

### Switching between semi-automatic and automatic mode.
- To switch from automatic mode to semi-automatic mode, set the key switch to ‘Auto’.
- To switch from semi-automatic mode to automatic mode, set the key switch to ‘Semi’.
- This is possible during production, without stopping the machine.

### Switching between semi-automatic / automatic mode and I/O test mode.
- To switch from automatic mode to I/O test mode, Stop de machine. Set the key switch to ‘Semi’. Select I/O  with the button on the main screen. Press the Start button on the ‘Control Panel’.
- To switch from semi-automatic mode to I/O test mode, Stop de machine. Select I/O test with the button on the main screen. Press the Start button on the ‘Control Panel’.

## Stopping
Press the stop button on the ‘Primary Control Panel’.  
The machine parts will return to the rest position and stop.

## Emergency stop
Use the emergency stop function only to avert imminent hazardous situations or machine damage. The emergency stop buttons are described in §6.6.  
Pressing one of the emergency stop buttons will result in an emergency shutdown of the machine, thereby stopping the drives and depressurizing the pneumatic and hydraulic circuits.  
  
After pressing one of the buttons, proceed as follows:
1. Bring personnel involved to safety / provide medical care if safety issues are involved.
1. Repair the damage if material aspects are involved. 
1. Release the pressed button by turning it until the button returns to the zero position. 
1. After that, the machine is ready to be restarted.
