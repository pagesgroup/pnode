# Description of the controls
## Primary Control Panel
The primary control panel is used to start / stop the machine and change machine settings. Below the location and layout are shown, explanation on the next page.

![Primary-control-panel-on-{{controlSide}}-side-1](assets/image/manual-primary-control-panel-{{controlSide}}-01.png)
  
![Primary-control-panel-on-{{controlSide}}-side-2](assets/image/manual-primary-control-panel-{{controlSide}}-02.png)
  
This panel is used to:
- Control the start and stop function.
- Determine the operating mode.
- View / change settings.

The controls on the primary control panel include:

- **'Start / Stop' pus buttons with light indicator**  
  The buttons start or stop the machine. Flashing indicator light means that the machine is starting up, steady light means that the machine is on (running).
- **'Manual / Auto' key switch**  
  This has two modes: manual control and automatic. Automatic mode is selected for production, manual control mode for settings or inspections.
- **'Service On / Off' key switch**  
  This switch is to enable service mode. When the key is turned to 'On' a door can be opened in manual control and with a 2 button configuration the program can be completed step by step (excep Manual Control 12). Also Manual Control 12 can only be used with the key switch 'On'. When the key switch is turned to 'Off' manual control with open door cannot be performed. FOr step by step control the doors now need to be closed. However Pilot Air and power supply remain activated.
- **'Emergency stop' push button**  
  This button is used to put the cell in safe mode in case of an imminent emergency situation.
- **'Step Manual Control' push button with light indicator**  
  When the machine is started in manual control mode and the light indicator is lit, the program can be completed step by step.
- **'Open Door' push button with light indicator**  
  This button is used to request access to the doors. The indicator flashes when a request is made. The controller puts the machine in a safe state. If this state is reached, the indicator remains lit and the door(s) may be opened. The access procedure terminates when the doors are closed and the push button is pressed again. If a door is opened without request and clearance, the machine responds with an emergency stop.
- **Touch screen**  
  This can be used to configure the machine, read error messages, and select manual control (see §7.5); for manual control the key switch should be set to 'Manual'. The available control and setting screens are described in Chapter 7.
- **USB**  
  USB-Connector for uploading of the touchscreen software.
- **Speaker**  
  To give audio warning signals.

- **'Main Switch' switch**  
  This is the main switch of the machine. By setting th switch to 'ON' the system will be energized. BY setting the switch to 'OFF' the system will be de-energized. To prevent unauthorizes access, thw switch can be locked on the 'OFF' position. This can be done by pressing the grey pawl and confirm a padlock in the hole.

## Signal lights
There are two signal lights on the machine.  
  
Blue light:
- Illuminates when a problem is detected, e.g. handle grip magazine is almost empty.
- Flashes to indicate a fault condition in the machine.

Red light:
- Flashes to indicate that the door is open after start-up of the machine in manual control and that compressed air is still present.

## Audio signal
The machine is equipped with a buzzer that generates:
- Intermittent sound when a problem is detected, e.g. handle grip magazine is almost empty.
- A continuous sound when a fault condition occurs in the machine.

The buzzer can be disabled, see 'Option', §7.3.5.

## Emergency stop buttons
Version and locations: see §5.7.  
  
Pressing one of the emergency stop buttons will result in an emergency shutdown of the machine. This mode is maintained until the butto is released (turning will return the button to the zero position). After that, the machine is ready to be restarted.
